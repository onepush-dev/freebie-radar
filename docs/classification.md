# 分类设置、误判诊断与人工纠正

所有常用操作在管理端完成，不需要手动编辑数据库。

## 按源固定分类

**管理区 → 数据源运维 → 搜索源 → 编辑 → 固定分类（硬规则）**。

- 固定分类优先于标题关键词、RSS 提示和 AI；保存立即重整该源所有保留的历史资源。
- **LINUX DO · 资源荟萃** 默认固定为“网盘资源”。新版迁移会补齐旧库配置、修正历史分类。
- 可改成课程、软件等任意本站分类，也可选择“不固定”。显式取消不会被默认配置重新开启。
- 兜底分类仅在内容识别不出时采用，AI 仍可改判；不要把它当固定分类。
- 固定分类不会启用被禁用的源、不删除内容、不调用 AI、不触发推送，也不改变收藏和隐藏状态。
- 取消固定只让新资源恢复自动分类，历史条目需检查后重整。

固定归网盘的内容不再进入真福利、好价、开源、资讯等主频道；“全部收录”、收藏及按 ID 查询仍能访问它们。分类不是权限控制。

## RSS 内容过滤

每条 RSS 地址都有表单，可设置：

- 只采这些 RSS 栏目 / 排除这些 RSS 栏目（原站 `<category>` 标签，排除优先）。
- 标题必含关键词（至少一个）/ 标题排除词（任一命中就跳过）。
- 每条地址自己的分类、用途提示；不会用第一条地址的提示错误覆盖其它地址。
- 每次条数与 URL。

逗号分隔。原站栏目如 `info, promotion` 不是本站分类；填 `pan` 并不等于固定网盘分类。采集过滤从下一次采集生效，不删除历史条目。新增 RSS 同样支持固定分类。

## 新闻误进好价：规则和 AI 双重收口

旧逻辑把导购来源里的新闻回退成好价，没有要求促销证据。现在：

- `deal` 必须有真实价格/促销/付费套餐/交易证据；新闻中的收入、亏损金额不是售价。
- `freebie` 必须有可领取或免费使用的对象；“免费、限时、额度、会员”等泛词不单独成立。
- `opensource` 必须有开源、源码或仓库证据；版本号本身不是开源。
- 网盘分享链接优先归资源分享，不因影视/软件/AI 标题混成会员/正版授权/AI额度；网盘会员和存储服务不直接当网盘资源。
- “如何领取…步骤教程”不是仅因“如何”就当求助；真正的求助提问仍可拦截。
- AI 提示词追加同样的边界及正反例，包含自定义主提示词场景。

| 内容 | 应有结果 |
|---|---|
| 全美航班停飞4小时，普通旅客当天实际遇到了什么 | 普通社区 `info`；权威源可为 `news`，不是好价 |
| 航空公司限时特价机票，单程99元 | 好价 |
| 公司财报收入 $500 亿 | 金额不是售价，不是好价 |
| Epic 游戏免费入库 / is Free via Epic | 真实福利保留 |
| 软件电影合集 + 夸克分享链接 | 网盘资源 |
| 百度网盘会员免费领一年 | 会员服务，不是分享文件 |

## 管理端试算与历史修正

**数据源运维 → 分类证据校验**：

- 校验开关默认开启，可在后台热切换；按源固定规则独立生效。
- 填标题、摘要、来源与模拟 AI 形态，查看规则、最终形态、证据。“规则试算”不实际调用模型。
- 历史检查扫描最近最多 6000 条有效资源，展示变化样本，不写数据库。
- “修正历史误分（0 Token）”确认后重算分类/分数，记录原分类，不重发消息、不取消收藏/隐藏，也不撤销 AI 拒绝。
- 复杂语义仍需人工抽样或 AI 重审，规则不能保证零误判；不要盲目全量重审烧额度。

## 单条人工移动

以管理员身份打开任意资源详情，展开 **“调整分类（管理员）”**：

1. 选“人工分类”（如网盘资源、网课/教程、软件授权）。
2. 需要“特价好价 → 行业资讯”时同时选“人工内容形态”；分类和形态是两个维度。
3. 可写纠正备注，点“保存人工分类”。
4. 点“恢复自动分类”可取消人工锁定，并按当前源规则/AI结论重新计算。

优先级：**人工纠正 > 源固定分类 > 内容证据校验 > 关键词/AI建议**。人工分类在重采、后台 AI 审核、历史重整及 CLI 写入时保持；SQLite 触发器额外保护不会被其它写入覆盖。可只固定一个维度，其余维度保持自动。

人工移动只改全站分类/形态，不改变发布/过期状态、不触发推送、不把被 AI 拒绝的条目重新放行。普通用户仅可修改个人状态，无法修改全站分类；备注和人工管理信息也不向普通接口返回。
